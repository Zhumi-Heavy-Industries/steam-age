# 蒸汽时代（steam-age）

一个以第一次工业革命为主题的 Minecraft 模组构想：真实的蒸汽机械，维多利亚时代的工业美感。

> **状态：构想阶段，还没有代码。** 这是第一版构想文档，会一直改。

## 为什么做

蒸汽在 Minecraft 里不算少见，但几乎都只是一个阶段，或者一种动力来源：

- **Create（机械动力）** 有锅炉和蒸汽机，但很抽象，只有热量等级，没有压力，也不太讲效率。
- **GregTech** 的蒸汽机器是通往电力之前的过渡阶段。
- **RotaryCraft** 的机械物理很硬核，可惜停在了 1.7.10。
- **Immersive Railroading** 的蒸汽机车非常写实，但只做火车。

还没有一个模组把**整个蒸汽时代当成主线**完整做出来，并且做出那个年代的美感：红砖厂房、铸铁拱顶、黄铜阀门、飞轮和连杆。这个项目想补上这一块。

## 核心理念

### 1. 美术为主

真实感先落在看得见、听得见的地方：

- **看得见：** 活塞往复、飞轮转动、连杆带着曲轴、压力表指针、安全阀喷出白汽、铆钉铁板。
- **听得见：** 蒸汽机的节奏随负载变化，汽笛声，锅炉压力过高时的嘶鸣。

### 2. 真实的物理，两种模式

底层只有一套物理计算：扭矩、转速、效率、煤耗、压力都按真实的方式算。玩家可以选两种玩法，区别只在于「给你看多少、出错时有多宽容」：

| | 简单模式 | 专业模式 |
|---|---|---|
| 底层计算 | 同一套真实计算 | 同一套真实计算 |
| 显示 | 「动力充足 / 不足」 | 扭矩、转速、功率、效率 |
| 变速 | 自动匹配，或者给宽松范围 | 自己配齿轮比 |
| 超限 | 报警、冒烟、停机，不坏东西 | 轴会断，锅炉会炸 |
| 科技路线和配方 | 完全相同 | 完全相同 |

两种模式的科技路线和配方完全一样，平衡只需要做一遍，两类玩家也能交流同一套玩法。模式按世界设定，不按玩家设定，这样联机时大家看到的是同一个结果。

### 3. 真实是为了好玩

- 压力过高时先报警、再泄压，给玩家反应时间，不会一言不合就爆炸。
- 效率的差距做成升级的爽感：换上瓦特机，同样一吨煤能干几倍的活，不用对着一堆算式发愁。

## 科技主线（草案）

沿着历史走，每一步都在解决上一步留下的问题：

1. **纽科门大气式蒸汽机（1712）：** 第一台实用的蒸汽机，用来给煤矿抽水。体积大、费煤，效率不到 1%。
2. **瓦特蒸汽机：** 1769 年发明分离式冷凝器，效率提高好几倍；1781 年用行星齿轮把往复运动变成旋转。从这时起，蒸汽机走出了矿井。
3. **冶铁：** 达比用焦炭炼铁（1709），科特发明搅炼法（1784）。有了便宜的铁，才造得出更大的锅炉和机器。
4. **纺织工厂：** 珍妮纺纱机（约 1764）、水力纺纱机（1769）、走锭纺纱机（1779）。一台蒸汽机通过天轴和皮带带动整个车间。
5. **高压蒸汽与铁路：** 特里维西克造出第一台蒸汽机车（1804），斯蒂芬森的「火箭号」跑出来（1829）。运河和铁路把整个工业体系连在一起。

整条线的核心是一个循环：**热源 → 锅炉 → 蒸汽 → 做功 → 冷凝 → 水回到锅炉**。科技树就是把这个循环做得越来越高效。

## 美术方向

- **材质：** 熟铁、铸铁、黄铜、木头、红砖。
- **建筑参考：** 维多利亚时代的纺织厂和烟囱、伦敦的帕丁顿站和圣潘克拉斯站、1851 年的水晶宫。
- **机器参考：** 纽科门机和瓦特机的历史版画、博物馆里保存的实物、「火箭号」。
- **做法：** 主要机器用独立的 3D 模型（Blockbench），不只靠 16×16 的方块贴图，否则铆钉和黄铜的质感出不来。

## 技术方向（初步）

- **先做 Create 附属，保留以后独立的可能。**
  - 核心层不依赖 Create，包括物理计算、机器、配方和多方块。
  - Create 通过一个「动力接口」接进来，只是动力的一种输出：把我们的扭矩和转速折算成 Create 的转速和应力。
  - 将来要独立，只需换掉接口后面的实现。
- **改规则不能毁掉玩家的存档。** 比如从简单模式切到专业模式时，已经超限的轴先报警，不会一下子全断。
- **从第一天起就有自动测试**，每个改动单独一个提交，写清楚为什么改。
- **MC 版本和加载器还没定。** 开工前先确认 Create 当前的主线版本。

## 第一个里程碑：纽科门抽水机

不一开始就做大，先做一个完整的小切片：

- 一台纽科门蒸汽机，多方块结构，有完整的模型和动画；
- 真的烧煤，有压力，有效率；
- 简单、专业两种模式都能玩；
- 用它给矿井抽水。

这一台手感对了，整个方向就验证了。瓦特机、纺织厂、火车都是在它的基础上往上加。
